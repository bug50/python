项目介绍
项目功能：生成高强度随机密码，支持自定义密码长度、是否包含数字、大小写字母、特殊符号，可批量生成多个密码。
实用价值 / 趣味性：非常实用的工具，再也不用担心密码安全问题，学习字符串处理和随机数的高级用法。

详细的步骤讲解
步骤 1：导入必要模块
random：随机数生成
string：提供预定义的字符集（数字、字母等）
步骤 2：核心生成函数设计
generate_password()是核心函数，有多个参数控制密码特性
默认参数让函数调用更灵活
步骤 3：构建字符池
根据用户选择，将不同类型的字符拼接到char_pool
string.digits、string.ascii_uppercase等是 string 模块提供的常量
步骤 4：确保密码多样性
这是关键细节：先确保每种选中类型至少有 1 个字符
避免生成全是字母的 "假强密码"
步骤 5：补充剩余字符并打乱
补充剩余长度的随机字符
重要：random.shuffle()打乱顺序，否则密码前几位的字符类型固定
步骤 6：用户设置交互
get_user_settings()收集用户偏好
嵌套函数get_yes_no()简化重复的是 / 否询问
步骤 7：密码强度评估
calculate_strength()从长度和字符多样性评分
any()函数简洁地检查是否包含某类字符
生成器表达式any(c.isdigit() for c in password)是 Pythonic 写法
步骤 8：主程序流程
循环生成直到用户退出
格式化输出让结果更美观
f"{i+1:2d}"数字右对齐，f"{password:{length}s}"密码对齐
4. 涉及的 Python 基础知识点
string 模块：预定义字符集常量
函数参数：默认参数、关键字参数
字符串操作：拼接、join()、格式化
列表操作：append()、shuffle()打乱
嵌套函数：函数内定义函数
生成器表达式：any(c.isdigit() for c in ...)
内置函数：any()、sum()、len()
字符串方法：isdigit()、isupper()、islower()、isalnum()
异常处理：try-except、raise抛出异常
格式化输出：f-string 的高级格式化（对齐、宽度）
循环与条件：while 循环验证输入、for 循环批量生成
