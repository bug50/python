项目介绍
项目功能：程序随机生成一个 1-100 之间的数字，玩家通过输入数字来猜测，程序会提示 "太大了" 或 "太小了"，直到猜对为止，最后统计猜测次数。
实用价值 / 趣味性：经典的入门游戏，能快速理解 Python 基础语法和逻辑控制，玩起来也很有成就感。

详细的步骤讲解
步骤 1：导入必要模块
使用import random导入随机数模块
这是 Python 标准库，不需要额外安装
步骤 2：初始化游戏数据
random.randint(1, 100)生成 1-100 的随机整数
guess_count = 0初始化计数器，记录猜测次数
步骤 3：打印欢迎信息
使用print()输出游戏说明
"=" * 40是字符串乘法，生成 40 个等号作为分隔线
步骤 4：主循环（while True）
while True创建无限循环，直到猜对才会 break 退出
这是游戏的核心逻辑
步骤 5：获取并验证用户输入
input()获取用户输入，返回的是字符串
使用try-except捕获输入非数字的情况
这是小白容易出错的地方：输入的内容必须用int()转换才能进行数字比较
步骤 6：判断猜测结果
使用if-elif-else条件判断
分别处理 "太小"、"太大"、"猜对" 三种情况
猜对时使用break退出循环
步骤 7：结果评价
根据猜测次数给出不同的评价
增加游戏的趣味性
4. 涉及的 Python 基础知识点
模块导入：import语句，使用标准库功能
变量与赋值：存储数据和计数器
数据类型：整数 (int)、字符串 (str) 的转换
print () 函数：输出内容到控制台
input () 函数：获取用户输入
while 循环：重复执行代码块
条件判断：if-elif-else分支结构
异常处理：try-except捕获错误
break 语句：跳出循环
字符串操作：字符串乘法、拼接
