项目介绍
项目功能：一个命令行的待办事项管理工具，支持添加、查看、删除、标记完成待办事项，数据保存在内存中。
实用价值 / 趣味性：真正实用的工具，可以用来管理日常任务，学习如何管理列表数据。

详细的步骤讲解
步骤 1：数据结构设计
使用列表todo_list存储所有待办事项
每个事项用字典存储，包含content（内容）和completed（完成状态）
这是小白需要理解的重点：列表嵌套字典的数据结构
步骤 2：函数封装
将每个功能封装成独立的函数：show_menu、add_todo、show_todos等
函数让代码结构更清晰，便于维护
函数定义用def关键字
步骤 3：菜单显示
show_menu()函数打印功能选项
用户通过输入数字选择功能
步骤 4：添加功能实现
获取用户输入，验证非空
创建字典并append()到列表
strip()去除首尾空白字符
步骤 5：显示功能实现
len(todo_list)判断列表是否为空
enumerate(todo_list, 1)遍历列表，同时获取索引（从 1 开始）
三元表达式"✅" if todo["completed"] else "⬜"简化条件判断
步骤 6：标记完成功能
用户输入编号，转换为索引（注意减 1）
修改字典的completed值为True
步骤 7：删除功能
pop(index)方法删除指定位置的元素
并返回被删除的元素用于提示
步骤 8：主程序逻辑
main()函数作为程序入口
if __name__ == "__main__":是 Python 的标准写法
确保脚本被直接运行时才执行主程序
4. 涉及的 Python 基础知识点
列表操作：append()、pop()、len()、索引访问
字典操作：键值对存储、访问、修改
函数定义：def关键字、参数、返回值
文档字符串：函数内的"""注释
for 循环：遍历列表、enumerate()函数
条件表达式：三元运算符简化代码
列表推导式：简洁的统计方式
字符串方法：strip()去除空白
程序入口：if __name__ == "__main__"
模块化设计：函数拆分、代码组织
